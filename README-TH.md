# FeatherShot 0.1.6

โปรแกรมแคปหน้าจอสำหรับ Windows 10/11 แบบ portable เขียนด้วย Rust และ Win32 โดยตรง ใช้หน้าต่างและปุ่มของ Windows ไม่มี WebView หรือวงจร polling ขณะรอ ปล่อยหน่วยความจำภาพเต็มเมื่อแคปเสร็จ และเก็บเฉพาะภาพย่อในหน้าหลัก

## เริ่มใช้งาน

1. แตก ZIP ทั้งโฟลเดอร์ไปไว้ในตำแหน่งที่เขียนไฟล์ได้
2. เปิด `FeatherShot.exe`
3. กด **Select region** แล้วลากเลือกพื้นที่ หรือใช้ปุ่มลัด
4. ไฟล์ PNG จะอยู่ในโฟลเดอร์ `Screenshots` ข้างโปรแกรม และถูกคัดลอกเป็นภาพเข้าคลิปบอร์ดเมื่อเปิด **Auto-copy**

กด **Esc** หรือคลิกขวาเพื่อยกเลิกการเลือกพื้นที่ กด **Open screenshots folder** เพื่อดูภาพทั้งหมด

คลิกหรือดับเบิลคลิกไอคอนใน system tray จะเปิดหน้าต่างหลัก ส่วนการแคปให้ใช้ปุ่มในโปรแกรม ปุ่มลัด หรือเมนูคลิกขวา

## เลือกหน้าตาเมื่อเปิดโปรแกรม

กดปุ่ม **On launch: Show window** ที่ด้านล่างหน้าหลักเพื่อสลับเป็น **On launch: System tray** แล้วโปรแกรมจะบันทึกค่าทันที มีผลเมื่อเปิดครั้งถัดไป:

- **Show window** — แสดงหน้าต่างหลักเมื่อเปิด (ค่าเริ่มต้น)
- **System tray** — เปิดเฉพาะไอคอนในถาดระบบ ใช้ปุ่มลัดแคปต่อได้ คลิกไอคอนเพื่อเปิดหน้าต่าง

กดปุ่มเดิมอีกครั้งเพื่อเปลี่ยนกลับ ค่านี้เลือกพฤติกรรมตอนเปิด FeatherShot เอง หาก Windows เพิ่มไอคอนถาดระบบไม่สำเร็จ โปรแกรมจะแสดงหน้าต่างให้ใช้งานได้

| การแคป | ปุ่มลัดเริ่มต้น |
|---|---|
| ลากเลือกพื้นที่ | Ctrl+Shift+S |
| คลิกเลือกหน้าต่าง | Ctrl+Shift+W |
| แคปทุกหน้าจอ | Ctrl+Shift+F |

## ตั้งค่าปุ่มลัดเอง

**ปิดปุ่มลัด Snipping Tool ขณะใช้ FeatherShot:** ใน **Customize hotkeys** เปิด **Block Snipping Tool shortcuts while running** แล้วกด **Save shortcuts** จะกัน PrtSc (ไม่มี modifier) และ Win+Shift+S ไม่ให้เรียก Snipping Tool ขณะ FeatherShot ทำงาน รวมถึงตอนซ่อนใน system tray ถ้าปุ่มนั้นตั้งให้ FeatherShot อยู่แล้ว จะยังแคปตามโหมดที่ตั้งไว้ หากไม่ได้ตั้งไว้ ปุ่มนั้นจะไม่ทำงาน ตัวเลือกเริ่มต้นเป็นปิด บันทึกไว้ใน settings.ini ปิดตัวเลือกแล้ว Save หรือ Quit เพื่อคืนการทำงานให้ Windows ไม่เปลี่ยน registry และยังเปิด Snipping Tool จาก Start ได้ตามปกติ

1. กด **Customize hotkeys** ในหน้าหลัก หรือจากเมนูคลิกขวาที่ไอคอนถาดระบบ
2. คลิกช่องของโหมดที่ต้องการ แล้วกดปุ่มชุดใหม่ เช่น **Ctrl+Alt+A** หรือ **Shift+F8** หากต้องการใช้ปุ่ม Windows ให้ติ๊ก **Win** ข้างช่อง เช่น บันทึก **Shift+S** แล้วติ๊ก **Win** จะได้ **Win+Shift+S**
3. กด **Save shortcuts** เพื่อใช้ค่าทันทีและบันทึกสำหรับครั้งถัดไป

รองรับ Win / Ctrl / Alt / Shift ร่วมกับปุ่มอื่น ปุ่ม F และ Print Screen สามารถใช้เดี่ยวได้ ยกเว้น F12 ซึ่ง Windows สงวนไว้ กด Backspace ในช่องเพื่อปิดปุ่มลัดของโหมดนั้น

**ใช้ Win+Shift+S แทน Snipping Tool:** กด **Use Win+Shift+S** แล้วกด **Save shortcuts** โปรแกรมจะดักชุดปุ่มนี้และแคปพื้นที่ด้วย FeatherShot เฉพาะตอนโปรแกรมเปิดอยู่ รวมถึงตอนซ่อนใน system tray เมื่อ Quit จะคืนการทำงานให้ Windows

**ใช้ PrtSc แคปทั้งจอ:** กด **PrtSc: All screens** แล้วกด **Save shortcuts** ปุ่มนี้เลือก Print Screen ให้โหมด All screens โดยตรงและเอา Win ออกให้อัตโนมัติ หากเคยตั้ง PrtSc แบบไม่มี modifier ให้โหมดอื่น จะย้ายมาให้ All screens เพื่อไม่ให้ปุ่มซ้ำกัน การเลือก Win+Shift+S สำหรับแคปพื้นที่ยังคงใช้คู่กันได้

ช่องตั้งค่าแสดงชุดปุ่มเต็มทันที เช่น **Win+Shift+S** และ **PrtSc** รวมทั้งตอนติ๊ก/เอาติ๊ก Win ออก จึงไม่ต้องอ่านแยกกับปุ่ม Win และไม่เห็นชื่อ `<00>` สำหรับ Print Screen หากพิมพ์ปุ่มเอง ช่องตั้งค่ารองรับ Print Screen ทั้งตอนกดและตอนปล่อย รุ่นนี้ใช้ตัวดักปุ่มโดยตรงสำหรับ Print Screen และรองรับอุปกรณ์ที่ส่งมาเฉพาะตอนปล่อย รวมถึง Print Screen ที่ส่งจากโปรแกรมคีย์บอร์ด แต่ละโหมดเลือกได้หนึ่งชุดปุ่ม

ตัวดักปุ่ม Win / Print Screen ทำงานบน thread แยกตามเหตุการณ์ ไม่ใช้ polling และไม่เก็บข้อความที่พิมพ์ ดักเฉพาะชุดปุ่มที่ตั้งไว้ ส่วนปุ่มอื่นและการปล่อยปุ่ม Win จะส่งต่อให้ Windows ตามปกติ ระบบจะสร้าง thread นี้เฉพาะเมื่อมีการตั้งค่าปุ่มลัดที่ใช้ Win หรือ Print Screen บางปุ่มที่ Windows สงวนไว้ เช่นการล็อกเครื่อง หรือปุ่มที่โปรแกรมอื่นดักไว้ อาจไม่สามารถแทนที่ได้

หากกำหนดปุ่มซ้ำระหว่างโหมด โปรแกรมจะแจ้งข้อผิดพลาดและเก็บปุ่มเดิมไว้ ปุ่มทั่วไปจะตรวจด้วยว่าถูกโปรแกรมอื่นจองอยู่หรือไม่ ส่วนปุ่มที่ใช้ Win หรือ Print Screen จะดักชุดปุ่มที่เลือกไว้โดยตรง สามารถสลับปุ่มเดิมระหว่างโหมดได้ **Restore defaults** จะใส่ค่าเริ่มต้นให้ตรวจดูก่อนกด Save

ค่าอยู่ใน `settings.ini` ข้างโปรแกรม หากโปรแกรมอื่นจองปุ่มไว้ก่อนเปิด FeatherShot จะมีข้อความให้เปลี่ยนปุ่มลัด โดยยังใช้ปุ่มแคปบนหน้าหลักได้

## เครื่องมือที่มี

- เลือกพื้นที่บนภาพหน้าจอที่หยุดค้าง รองรับพิกัดจอที่อยู่ทางซ้ายหรือด้านบนของจอหลัก
- เลือกหน้าต่างจากพื้นที่ที่แสดงอยู่ หรือแคปพื้นที่รวมทุกจอ
- ตั้งหน่วงเวลา 0 / 3 / 5 วินาที และเลือกให้รวมเคอร์เซอร์ได้
- บันทึก PNG ชื่ออัตโนมัติและคัดลอกภาพเข้าคลิปบอร์ด
- กด **Annotate** เพื่อเพิ่มลูกศร กรอบ ปากกา หรือปิดทับข้อมูลแบบทึบ
- เลือกสี 4 สี ขนาดเส้น 3 ขนาด พร้อม Undo / Redo
- พักในถาดระบบ กด X หรือ **Hide to tray** แล้วใช้ปุ่มลัดต่อได้ ออกจากโปรแกรมด้วย **Quit**

## ตัวแก้ไขภาพ

| ปุ่ม | การทำงาน |
|---|---|
| 1 / 2 / 3 / 4 | ลูกศร / กรอบ / ปากกา / ปิดทับ |
| Ctrl+Z | ย้อนกลับ |
| Ctrl+Y หรือ Ctrl+Shift+Z | ทำซ้ำ |
| Ctrl+S | บันทึกเป็น PNG ใหม่ |
| Ctrl+C | คัดลอกภาพที่แก้ไขแล้ว |
| Esc | ปิดตัวแก้ไข โดยถามบันทึกหากมีการแก้ไข |

**Redact** เขียนทับพิกเซลในภาพส่งออกด้วยสีทึบ **Save PNG** จะสร้างไฟล์ใหม่ชื่อมี `-edited` ภาพต้นฉบับที่แคปไว้ยังอยู่ใน `Screenshots` เมื่อต้องการแชร์ภาพที่ปิดทับ ให้ใช้ไฟล์ edited หรือ Copy image จากตัวแก้ไข

## ขอบเขตรุ่นแรก

รุ่นนี้เน้นภาพนิ่ง ยังไม่มีอัดวิดีโอ, GIF, scrolling capture, OCR หรืออัปโหลดเว็บ การเลือกหน้าต่างแคปพิกเซลที่มองเห็นบนจอ จึงรวมส่วนที่หน้าต่างอื่นบังอยู่ด้วย และแคปหน้าต่างที่ย่อไว้ไม่ได้ เนื้อหาที่ป้องกันการแคปหรือภาพ HDR อาจแสดงไม่ครบ/สีต่างจากต้นฉบับ

ทดสอบ API แคปหน้าจอ การคืน GDI objects และระบบปุ่มลัดแล้ว การทดสอบลากด้วย UI, คลิปบอร์ดในแอปปลายทาง และการต่อหลายจอที่ใช้ DPI ต่างกันยังไม่ครบ ดู `VALIDATION-TH.md`

## พัฒนาและคอมไพล์

ใช้ Rust stable บน Windows กับ C++ Build Tools + Windows SDK ตามปกติ:

```powershell
cargo build --release --locked
cargo test --locked
```

หรือใช้ GNU toolchain ผ่าน `build.ps1`:

```powershell
rustup toolchain install stable-x86_64-pc-windows-gnu
.\build.ps1 -Test
```

ถ้า GNU linker ต้องใช้ assembler เพิ่ม ให้ตั้ง `$env:FEATHERSHOT_MINGW_BIN` ไปยังโฟลเดอร์ `bin` ของ MinGW-w64 / w64devkit สคริปต์รองรับ toolchain ที่มีอยู่ใน workspace นี้อยู่แล้ว การ build ด้วยสคริปต์ใช้ `--offline` จึงต้องมี dependencies ใน Cargo cache ก่อน หรือรัน `cargo fetch --locked` ครั้งแรก

`windres` (GNU) หรือ `rc` (MSVC) ใช้ฝังไอคอน เวอร์ชัน และ DPI manifest หากไม่มีจะ build ได้พร้อมคำเตือน โดยยังตั้ง DPI awareness ผ่าน Win32 เมื่อเปิดโปรแกรม

พารามิเตอร์เพิ่มเติม: `--tray` บังคับเปิดในถาดระบบ, `--show` บังคับแสดงหน้าต่าง (มีลำดับเหนือ `--tray` และค่าที่บันทึก), `--data-dir <folder>` เปลี่ยนตำแหน่ง `settings.ini` และ `Screenshots` หากโปรแกรมเปิดอยู่แล้วและตั้งเป็น System tray การเปิดซ้ำจะไม่เรียกหน้าต่างขึ้นมา ใช้ไอคอนถาดระบบหรือ `--show` เพื่อแสดงได้

โครงสร้างซอร์ส: `src/main.rs` หน้าต่าง/ถาดระบบ/ตัวแก้ไข, `src/hotkey.rs` ตัวบันทึกและจองปุ่มลัด, `src/winhook.rs` ตัวดักชุดปุ่ม Win, `src/platform.rs` แคป/คลิปบอร์ด/Win32, `src/image.rs` พิกเซล/PNG/annotations
